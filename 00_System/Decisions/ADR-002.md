# ADR-002: ChatGPT Projects · AI 研究与学习工作空间

文档版本：1.0.0 | 架构目标：V1.1

更新时间：2026-11-11（Asia/Shanghai）

## Status

**Accepted（当前工作空间选择）**。决策人：PAIOS 负责人（用户）；本次补录日期：2026-11-11。依据：用户本次任务与既有进度笔记；原始选型日期未知。

验证状态：既有笔记报告已建立四个 Projects，但本次未进入账号验证。统一项目指令在原笔记中仍为未完成；不能据本地文件夹推断平台配置已生效。任务效果、上下文完整性及成果沉淀均待验证。

## Context

研究和学习需要围绕主题保留任务上下文，并允许多个会话持续推进。用户已选择 ChatGPT Projects，但 PAIOS 的设计方法不能只保存在平台指令或聊天中。

## Decision

当前采用 ChatGPT Projects 承载研究、学习及相关主题的 AI 工作会话；每次任务有明确交付物，重要成果与决策回存 Markdown。Projects 是工作空间，`00_System/` 仍是系统规范的主来源。

官方文档说明，Projects 可组织相关聊天、文件、指令与来源，项目指令用于项目内聊天。此能力支持该选择的设计意图，但不证明当前账号已完成配置或所有会话都读取了所需资料。[OpenAI 官方文档：Projects and chats](https://learn.chatgpt.com/docs/projects?surface=app)（核查日期：2026-11-11）。

## Alternatives

| 方案 | 本项目的取舍 |
| --- | --- |
| 普通独立聊天 | 适合短任务；持续主题需要反复交接相关资料 |
| ChatGPT Projects | 沿用已有选择，用来组织主题及任务上下文；效果需要实际任务评估 |
| 其他 AI 工作空间或本地工具 | 可替换候选；通过同一 Markdown 输入输出协议比较，不预设必须迁移 |

## Reasons

减少同一主题的上下文重建，区分研究、学习及项目任务，延续已有使用习惯。这些是预期收益，尚无测量结果；不承诺永久完整记忆、自动同步 Vault 或特定额度。

## Consequences

**Positive（预期）**：主题组织更清晰，可复用当前任务所需上下文。

**Negative**：平台状态可能与本地规范版本不同；仍需主动保存成果、补充遗漏资料；平台功能与账号能力会变化。云端工作空间不能仅凭本地路径获得文件，实际访问方式须核查。

恢复/替换：使用 [Global](../AI_Instructions/Global.md) 与角色指令在新工具中建立任务，提供相关 Markdown 资料；能否继续完成任务需做可移植性检查。

## Review Trigger

经常丢失上下文、指令副本漂移、成果难以沉淀、费用或可用性不满足需要，或另一工具在可比任务中表现更合适。
